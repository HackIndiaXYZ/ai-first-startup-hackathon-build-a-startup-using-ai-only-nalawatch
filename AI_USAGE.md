# AI usage report

## AI-first workflow

AI was used as a primary builder for startup framing, product copy, interface structure, React implementation, styling, test creation, documentation, and iterative debugging. The human role is to review outputs, verify claims and behavior, run tests, and make final submission and safety decisions.

The project uses AI assistance during development; the deployed prototype does **not** call an AI model. Its scenario output is a deterministic synthetic bucket-model exercise with illustrative ward factors and scenario-index thresholds. These values are not research-derived or validated. Do not describe the output as machine learning or flood prediction.

## Tool disclosure

- AI assistant in VS Code using Copilot SDK: ideation, code and copy generation, implementation iteration, test/debug support, and documentation.
- React, Vite, Vitest, ESLint, and Git: application and validation tooling.
- GitHub Actions/Linux runner: automated lint, tests, and production build.
- Optional Docker/Nginx: reproducible static container packaging.
- Open-Meteo Forecast API: optional, user-triggered hourly precipitation context for preset Indian cities. It is a weather-data dependency, not an AI model, and it does not generate NalaWatch flood-risk predictions. The request sends the selected city's coordinates; see the current [terms](https://open-meteo.com/en/terms) and [license](https://open-meteo.com/en/licence) before use.
